\section*{Sequential Play as an Equilibrium-Refinement Mechanism}

The purpose of this appendix is to make precise the informal claim from
the main text:

\begin{quote}
\emph{When the sneaky prover sees the honest solution before moving
(sequential, verifier-first Stackelberg play), all equilibria that rely
on purely stylistic cues disappear; the verifier is forced to use only
features that are genuinely tied to correctness / back-door presence.}
\end{quote}

\subsection*{B.1 Copyable versus Robust Features}

We begin by formalizing the distinction between stylistic and semantic features.

\begin{definition}[Feature Space]\label{def:B.feature}
Let $\Phi: \mathcal{Z} \to \mathcal{F}$ be a Borel-measurable map from the solution space $\mathcal{Z}$ to a feature space $\mathcal{F}$, which we assume is a Polish space. We assume a fixed Borel partition of the feature space into two disjoint sets:
\[
  \mathcal{F} = \mathcal{F}_{\mathrm{spurious}} \cup \mathcal{F}_{\mathrm{robust}}
\]
where $\mathcal{F}_{\mathrm{spurious}}$ represents stylistic ("spurious") features and $\mathcal{F}_{\mathrm{robust}}$ represents semantic ("robust") features. Let $\Phi_{spur}$ and $\Phi_{rob}$ be the projections of $\Phi$ onto these respective subspaces.
\end{definition}

\begin{definition}[Copyable Features]\label{def:B.copy}
A set of spurious features, represented by a map $\Psi: \mathcal{Z} \to \mathcal{F}_{\mathrm{spurious}}$, is \emph{copyable} if for every pair of solutions $(z, z') \in \mathcal{Z} \times \mathcal{Z}$, there exists a transformation $T_{z \to z'}: \mathcal{Z} \to \mathcal{Z}$ such that for the transformed solution $\tilde{z} = T_{z \to z'}(z)$:
\begin{enumerate}
    \item The spurious features are copied: $\Psi(\tilde{z}) = \Psi(z')$.
    \item The robust features are preserved: $\Phi_{rob}(\tilde{z}) = \Phi_{rob}(z)$.
    \item Correctness is preserved: $\corr(x, \tilde{z}) = \corr(x, z)$ for any $x \in \mathcal{X}$.
    \item Backdoor success is preserved: $\success(x, \tilde{z}) = \success(x, z)$ for any $x \in \mathcal{X}$.
\end{enumerate}
\end{definition}

\begin{assumption}[Spurious Features are Copyable]\label{ass:B.Cspu}
All features in $\mathcal{F}_{\mathrm{spurious}}$ are copyable. This formalizes the intuition that stylistic elements like code formatting, variable naming conventions, or sentence structure can be imitated without changing the underlying logic of a solution.
\end{assumption}

\begin{assumption}[Robust Features are Separable]\label{ass:B.Hrobust}
There exists at least one robust feature on which the honest and sneaky provers' outputs are statistically distinguishable. Formally, for any $\pi_H$, the sneaky prover's best response $\pi_S^* = \mathrm{BR}_S(\cdot, \pi_H)$ produces a distribution $\mathcal{D}_S$ that is separable from $\mathcal{D}_H$ on $\mathcal{F}_{\mathrm{robust}}$. This implies that for any two such distributions, the optimal Bayes error is less than $1/2$.
\end{assumption}

\subsection*{B.2 Verifier Loss in the Sequential Game}

We now analyze the verifier's loss for strategies based on spurious versus robust features. The verifier's loss is given by the Bradley-Terry objective:
\[
L_V(V, \pi_H, \pi_S) = \mathbb{E}_{x \sim P_X} \left[ \log(1 + e^{-(V(x, \pi_H(x)) - V(x, \pi_S(x, \pi_H(x))))}) \right]
\]

\begin{lemma}[Vulnerability of Spurious Verifiers]\label{lem:B.spur_loss}
Let $V_{spur}$ be any verifier that depends only on spurious features, i.e., $V_{spur}(x, z) = f(x, \Phi_{spur}(z))$ for some function $f$. In the sequential game, the sneaky prover's best response $\pi_S^* = \mathrm{BR}_S(V_{spur}, \pi_H)$ results in a verifier loss of $L_V(V_{spur}, \pi_H, \pi_S^*) = \ln 2$.
\end{lemma}

\begin{proof}
In the sequential game, for a given $x$ and $z_H = \pi_H(x)$, the sneaky prover $\pi_S$ chooses $z_S$ to maximize its utility. By reward axiom (R2), this involves maximizing $V_{spur}(x, z_S)$ for a backdoored solution. By Assumption \ref{ass:B.Cspu}, the sneaky prover can take any canonical backdoored solution and transform it to have the same spurious features as $z_H$ without altering its backdoored nature. Let this best-response solution be $z_S^*$. Then $\Phi_{spur}(z_S^*) = \Phi_{spur}(z_H)$. Since $V_{spur}$ depends only on these features, $V_{spur}(x, z_S^*) = V_{spur}(x, z_H)$. The verifier's score difference is zero, and the loss is $\mathbb{E}_x[\log(1 + e^0)] = \ln 2$.
\end{proof}

\begin{lemma}[Efficacy of Robust Verifiers]\label{lem:B.rob_loss}
Under Assumption \ref{ass:B.Hrobust}, there exists a verifier $V_{rob}$ that depends only on robust features and achieves a loss $L_V(V_{rob}, \pi_H, \pi_S^*) < \ln 2$.
\end{lemma}

\begin{proof}
Assumption \ref{ass:B.Hrobust} states that the distributions of honest and sneaky solutions are statistically separable based on robust features. The Bradley-Terry loss is a strictly proper scoring rule. For separable distributions, an optimal classifier can achieve an expected loss strictly lower than the loss for random guessing, which is $\ln 2$. A sufficiently expressive verifier class $\mathcal{V}$ will contain a verifier $V_{rob}$ that leverages this separability to achieve a loss strictly less than $\ln 2$.
\end{proof}

\subsection*{B.3 Sequential Play as an Equilibrium Refinement}

The following theorem is the central result, establishing that sequential play makes spurious features strategically irrelevant.

\begin{theorem}[Refinement under Sequential Play]\label{thm:B.refine}
Let $(V^*, \pi_H^*, \pi_S^*)$ be an $(\varepsilon_V, \varepsilon_H, \varepsilon_S)$-Verifier-First Stackelberg Equilibrium (VFSE).
\begin{enumerate}
    \item If $\varepsilon_V$ is sufficiently small, $V^*$ must depend on robust features.
    \item There exists a verifier $V'$ that is independent of all spurious features, and a constant $\varepsilon_H' \le \varepsilon_H$, such that $(V', \pi_H^*, \pi_S^*)$ is an $(\varepsilon_V, \varepsilon_H', \varepsilon_S)$-VFSE.
\end{enumerate}
\end{theorem}

\begin{proof}
1.  \textbf{Necessity of Robust Features:} By Lemma \ref{lem:B.spur_loss}, a verifier relying only on spurious features incurs a loss of $\ln 2$. By Lemma \ref{lem:B.rob_loss}, the optimal loss achievable with robust features, $L_{V,rob}^*$, is strictly less than $\ln 2$. An equilibrium verifier $V^*$ must be $\varepsilon_V$-optimal, so $L_V(V^*) \le L_{V,rob}^* + \varepsilon_V$. If $\varepsilon_V < \ln 2 - L_{V,rob}^*$, then $L_V(V^*) < \ln 2$, which is impossible for a purely spurious verifier. Thus, $V^*$ must depend on robust features.

2.  \textbf{Construction of an Equivalent Robust Equilibrium:} Let the equilibrium verifier be $V^*(x, z) = f(x, \Phi_{rob}(z), \Phi_{spur}(z))$. We construct a new verifier $V'$ that is "agnostic" to the style of its input by fixing the style component to that of the equilibrium honest policy $\pi_H^*$:
    \[
    V'(x, z) := f(x, \Phi_{rob}(z), \Phi_{spur}(\pi_H^*(x)))
    \]
    By construction, $V'$ is independent of $\Phi_{spur}(z)$. We now show that $(V', \pi_H^*, \pi_S^*)$ is also a VFSE.

    *   **(V) Verifier's Loss:** In the original equilibrium, the sneaky prover's best response $\pi_S^*$ must copy the style of the honest prover, so $\Phi_{spur}(\pi_S^*(x, \pi_H^*(x))) = \Phi_{spur}(\pi_H^*(x))$. The score difference under $V^*$ is $V^*(z_H^*) - V^*(z_S^*)$. The score difference under $V'$ is $V'(z_H^*) - V'(z_S^*)$. By evaluating both using the definitions of $V^*$ and $V'$ and the fact that styles are copied, we see the score differences are identical. Thus, $L_V(V', \pi_H^*, \pi_S^*) = L_V(V^*, \pi_H^*, \pi_S^*)$, so the $\varepsilon_V$ condition holds.

    *   **(S) Sneaky Prover's Incentive:** The best response for the sneaky prover to $(V', \pi_H^*)$ is to choose $z_S$ to maximize $V'(x, z_S) = f(x, \Phi_{rob}(z_S), \Phi_{spur}(\pi_H^*(x)))$. This is the same optimization problem faced by $\pi_S^*$ in the original game, as it too had to adopt the style $\Phi_{spur}(\pi_H^*(x))$. Thus, $\pi_S^*$ remains a best response, and the $\varepsilon_S$ condition holds.

    *   **(H) Honest Prover's Incentive:** This is the crucial step. We must show that $\pi_H^*$ remains an $\varepsilon_H'$-best response to $V'$ with $\varepsilon_H' \le \varepsilon_H$. The honest prover's utility depends only on its own policy and the verifier: $U_H(V, \pi_H) = \mathbb{E}_x[r(V(x, \pi_H(x)), \corr(x, \pi_H(x)))]$.

        The sub-optimality of $\pi_H^*$ under $V^*$ is $\varepsilon_H = \sup_{\pi_H'} U_H(V^*, \pi_H') - U_H(V^*, \pi_H^*)$.
        The sub-optimality of $\pi_H^*$ under $V'$ is $\varepsilon_H' = \sup_{\pi_H'} U_H(V', \pi_H') - U_H(V', \pi_H^*)$.

        First, note that the utility on the equilibrium path is unchanged: $U_H(V', \pi_H^*) = U_H(V^*, \pi_H^*)$ because $V'(x, \pi_H^*(x)) = V^*(x, \pi_H^*(x))$.

        Next, consider the maximum possible utility a deviating prover could achieve. For any deviation policy $\pi_H'$, the score under $V'$ is $V'(x, \pi_H'(x)) = f(x, \Phi_{rob}(\pi_H'(x)), \Phi_{spur}(\pi_H^*(x)))$. The prover can only optimize its robust features. Under $V^*$, the score is $V^*(x, \pi_H'(x)) = f(x, \Phi_{rob}(\pi_H'(x)), \Phi_{spur}(\pi_H'(x)))$. The prover can optimize both robust and spurious features.

        Therefore, for any $x$, the maximum achievable score under $V^*$ is greater than or equal to that under $V'$:
        \[
        \sup_{z: \corr(x,z)=1} V^*(x, z) \ge \sup_{z: \corr(x,z)=1} V'(x, z)
        \]
        Since the reward function $r(s,1)$ is increasing in score $s$, this implies that the maximum possible utility is also higher under $V^*$: $\sup_{\pi_H'} U_H(V^*, \pi_H') \ge \sup_{\pi_H'} U_H(V', \pi_H')$.

        Combining these facts:
        \[
        \varepsilon_H' = \sup_{\pi_H'} U_H(V', \pi_H') - U_H(V', \pi_H^*) \le \sup_{\pi_H'} U_H(V^*, \pi_H') - U_H(V^*, \pi_H^*) = \varepsilon_H
        \]
        The incentive for the honest prover to deviate is no greater (and possibly smaller) under $V'$ than under $V^*$. Thus, $\pi_H^*$ remains an $\varepsilon_H'$-best response with $\varepsilon_H' \le \varepsilon_H$.

    All conditions for a VFSE are met. This proves that for any equilibrium $(V^*, \pi_H^*, \pi_S^*)$, there is an equivalent equilibrium $(V', \pi_H^*, \pi_S^*)$ where the verifier $V'$ is independent of spurious features.
\end{proof}

\subsection*{B.4 Take-away}

This analysis provides a rigorous foundation for the claim that sequential play is a powerful equilibrium refinement mechanism. By giving the sneaky prover the ability to observe and imitate the honest prover's output, the game structure renders purely stylistic signals strategically useless for the verifier. Any equilibrium must be sustained by the verifier's ability to discriminate based on robust, semantic features that are intrinsically linked to correctness and deception. This forces the training process to converge towards verifiers that are not just accurate on a fixed data distribution but are genuinely robust against adversaries capable of stylistic adaptation.
